# SOPHIA

Bienvenido al repositorio **SOPHIA** de *Soffy Avila*.

Este repositorio reúne ejercicios y material de clase relacionados con programación, organizados de forma sencilla para facilitar el aprendizaje y la práctica.

---

## 📌 Descripción

**SOPHIA** es un proyecto educativo que contiene ejemplos y ejercicios de programación, pensado como apoyo para clases y estudio autónomo.  
Aquí encontrarás código organizado por temas, ideal para reforzar conceptos básicos y practicar.

---

## 📁 Estructura del repositorio

```
/
├── .vscode/        # Configuración de Visual Studio Code
├── clases/         # Material de clases
├── ejercicios/     # Ejercicios prácticos
└── README.md       # Documentación del repositorio
```

---

## 🚀 Cómo usar este repositorio

1. Clona el repositorio:
   ```bash
   git clone https://github.com/sophy44/SOPHIA.git
   ```

2. Abre el proyecto en tu editor de código favorito (por ejemplo, VS Code).

3. Explora las carpetas:
   - **clases/** para contenido teórico o ejemplos.
   - **ejercicios/** para practicar.

---
